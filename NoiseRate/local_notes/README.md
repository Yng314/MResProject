# Local notes

This directory holds working material that is useful on the cluster but is not part of the public source release. It is grouped into `literature_review/`, `meeting_materials/`, and `analysis_audits/` so that notes do not mix with executable experiment drivers.

The note files remain local because they may contain internal discussion, detailed interim interpretations, or references to private result paths. Public protocol and reproducibility documents belong under `cxr_real_experiment/` and are reviewed separately.
